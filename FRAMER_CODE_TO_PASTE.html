🚀 Framer Link Control Setup

Follow these steps to prevent users from opening Framer links in new tabs:

Step 1: Copy This Code

Copy the code below and paste it into your Framer project:

<script> // Framer Link Control - Prevents opening links in new tabs (function() { 'use strict'; const MAIN_DOMAIN = 'https://ihirwe.art'; const FRAMER_DOMAIN = 'https://ihirweui.framer.website'; function notifyParentNavigation(path) { if (window.parent && window.parent !== window) { window.parent.postMessage({ type: 'framer-navigation', path: path }, MAIN_DOMAIN); } } // Override all link clicks document.addEventListener('click', function(e) { const link = e.target.closest('a'); if (link && link.href) { if (link.href.startsWith(FRAMER_DOMAIN) || link.href.startsWith('/')) { e.preventDefault(); let targetPath = link.href; if (targetPath.startsWith(FRAMER_DOMAIN)) { targetPath = targetPath.replace(FRAMER_DOMAIN, ''); } window.location.href = FRAMER_DOMAIN + targetPath; notifyParentNavigation(targetPath); } } }, true); // Disable right-click context menu on links document.addEventListener('contextmenu', function(e) { const link = e.target.closest('a'); if (link && (link.href.startsWith(FRAMER_DOMAIN) || link.href.startsWith('/'))) { e.preventDefault(); } }); // Override middle-click (wheel click) document.addEventListener('mousedown', function(e) { if (e.button === 1) { const link = e.target.closest('a'); if (link && (link.href.startsWith(FRAMER_DOMAIN) || link.href.startsWith('/'))) { e.preventDefault(); let targetPath = link.href; if (targetPath.startsWith(FRAMER_DOMAIN)) { targetPath = targetPath.replace(FRAMER_DOMAIN, ''); } window.location.href = FRAMER_DOMAIN + targetPath; notifyParentNavigation(targetPath); } } }); // Disable keyboard shortcuts for new tabs document.addEventListener('keydown', function(e) { const link = document.activeElement; if (link && link.tagName === 'A' && (link.href.startsWith(FRAMER_DOMAIN) || link.href.startsWith('/'))) { if ((e.ctrlKey || e.metaKey) && (e.key === 'Enter' || e.type === 'click')) { e.preventDefault(); let targetPath = link.href; if (targetPath.startsWith(FRAMER_DOMAIN)) { targetPath = targetPath.replace(FRAMER_DOMAIN, ''); } window.location.href = FRAMER_DOMAIN + targetPath; notifyParentNavigation(targetPath); } } }); window.addEventListener('load', function() { notifyParentNavigation(window.location.pathname); }); console.log('✅ Link Control: Active - All links will stay within ihirwe.art'); })(); </script>

Step 2: Add to Framer

  1. Open your Framer project
  2. Go to Site Settings (gear icon)
  3. Click on General tab
  4. Scroll down to Custom Code
  5. Paste the code in the "End of <head> tag" section
  6. Click Save
  7. Publish your site

Step 3: Test It

After publishing:

  • ✅ Right-click on links → Context menu disabled
  • ✅ Middle-click on links → Opens in same tab
  • ✅ Ctrl+Click → Opens in same tab
  • ✅ All navigation stays within ihirwe.art

✅ What This Does

  • Prevents new tabs: All internal links open in the same tab
  • Disables right-click: Users can't "Open link in new tab"
  • Blocks shortcuts: Ctrl+Click, middle-click disabled
  • Maintains branding: URLs always show ihirwe.art
  • SEO friendly: Search engines see proper URLs
